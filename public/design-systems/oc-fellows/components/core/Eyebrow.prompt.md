The small line above a section heading. Write it as a human claim ("Future Leaders Making a Difference"), with the heading below as the plain label ("Meet the OC Fellows"). Never swap them.

```jsx
<Eyebrow>Leading with Purpose, Impact, and Unity</Eyebrow>
<h2>Our Values</h2>
```

Use `tone="inverse"` on navy. `uppercase` is for the tagline lockup only.
