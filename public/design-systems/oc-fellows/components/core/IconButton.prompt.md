Single-glyph control for carousel arrows, social links and close buttons — always pass `label`.

```jsx
<IconButton icon={<i data-lucide="arrow-right" />} label="Next story" variant="outline" />
<IconButton icon={<i data-lucide="linkedin" />} label="LinkedIn" variant="solid" />
```

Circles by default. Use `accent` only when the button is the primary action in its region.
